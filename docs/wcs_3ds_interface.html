WCS ↔ 3D Sorter · Modbus Interface

WCS ↔ 3D Sorter (VEICHI PLC) 인터페이스 정의 WCS = Modbus 마스터(주기 폴링) · PLC = 슬레이브. 셀 지정(IF-11)·적재 완료(IF-12)·상태/층 제어. ※ 레지스터 주소·시간값은 예시(현장 확정).

3 핸드셰이크 프로토콜

공통 규칙 — ① 쓰기 전 해당 Flag=0 확인(아직 안 읽힌 값 덮어쓰기 방지). ② 쓴 쪽이 Flag=1, 읽은 쪽이 Flag=0으로 내림(대칭). ③ C_Flag/R_Flag로 한 건씩 직렬 처리.

C 영역 — 셀 지정 (WCS → PLC)

  1. WCS: C_Flag==0 확인 → C_CellNo·C_Seq 쓰기 → C_Flag=1
  2. PLC: C_Flag=1 감지 → C_CellNo·C_Seq 읽기 → 읽은 직후 C_CellNo·C_Seq·C_Flag = 0 클리어 → 해당 셀로 적재 수행

R 영역 — 적재 완료 (PLC → WCS)

  1. PLC: R_Flag==0 확인 → 적재 결과 R_CellNo·R_Seq 쓰기 → R_Flag=1
  2. WCS: R_Flag 폴링 → 1이면 R_CellNo·R_Seq 읽기 → R_Seq == C_Seq 대사(유실·중복 검출) → R_CellNo·R_Seq·R_Flag = 0 클리어
요약 — “쓰는 쪽은 Flag=0 확인 후 쓰고 1로 set, 읽는 쪽은 읽고 0으로 clear.” C는 WCS가 쓰고 PLC가 클리어, R은 PLC가 쓰고 WCS가 클리어 — 대칭. C_Flag(D4.0)·R_Flag(D4.1)는 같은 워드 D4의 비트이므로, set/clear 시 D4를 읽어 해당 비트만 바꿔 다시 쓴다(read-modify-write · 상대 플래그 비트 보존).

타이밍 차트 ① — 셀 지정 → 적재 완료 (C/R 핸드셰이크)

  1. ① WCS 쓰기 — C_Flag==0 확인 → C_CellNo·C_Seq 쓰기 → C_Flag=1
  2. ② PLC 읽고 클리어 — PLC가 C_Flag=1 보고 C 값 읽음 → C_CellNo·C_Seq·C_Flag=0 클리어
  3. ③ N초 → 적재 — PLC가 N초 대기(틸트 낙하 안착) 후 지정 셀에 적재
  4. ④ PLC 통지 — R_Flag==0 확인 → R_CellNo·R_Seq 쓰기 → R_Flag=1
  5. ⑤ WCS 읽고 클리어 — WCS가 R_Flag 폴링 → R 값 읽고 R_Seq==C_Seq 대사 → R_CellNo·R_Seq·R_Flag=0 클리어

4 층 제어 (폐루프)

3D가 1·2층을 오가며 AGV로부터 트레이를 받는다. 투입 가부(IF-08) 처리 시 층을 맞춘다.

  1. WCS: IF-08에서 CurFloor(D5)와 상태(Ready D4.2)를 읽어 AGV 층·수용 가능 여부와 비교 (Ready=0 = 분류 중 또는 이동 중)
  2. 분류 중 아님(Ready=1) + 층 일치 → allowed=true (투입 진행)
  3. 분류 중 아님(Ready=1) + 층 다름 → WRONG_FLOOR 반환 → RCS가 500ms 간격 재호출
  4. 분류 중 또는 이동 중(Ready=0 / BUSY) → allowed=false(BUSY) → RCS 재호출. 분류 중이면 곧 끝나므로 아래 조건으로 TgtFloor를 미리 써 둔다(이동 중이면 이미 TgtFloor가 설정됨)
  5. TgtFloor 쓰기 조건 — TgtFloor==0 이고 (층 다름 또는 분류 중)이면 WCS가 TgtFloor(D6)에 AGV 층을 쓴다 → 층 다르면 그 층으로 이동, 분류 중이면 분류를 마친 뒤 그 층으로 복귀
  6. PLC: TgtFloor 층으로 이동(또는 분류 후 복귀) → 도착하면 CurFloor(D5)에 도착 층 기입 (TgtFloor는 유지)
  7. PLC: 분류를 시작할 때(Ready=0 진입) TgtFloor=0 클리어 — 도착 즉시 비우면 곧바로 다시 써져 왕복할 수 있어, 분류 시작까지 그 층을 붙들어 둔다
TgtFloor 쓰기 = 0일 때 + (층 다름 또는 분류 중) — 이전 명령이 진행 중(TgtFloor≠0)이면 덮어쓰지 않아 핑퐁(왕복)을 차단하고, 층이 다르거나 분류 중이면 AGV 층을 써서 그 층으로 이동/복귀시킨다. 도착 시엔 PLC가 CurFloor만 기입하고(TgtFloor 유지), 분류를 시작할 때(BUSY 진입) TgtFloor=0 클리어 — 도착 즉시 비우면 곧바로 다시 써져 왕복하므로 분류 시작까지 그 층을 붙든다. FULL·PAUSED·OFFLINE은 장기 차단이라 이동시켜도 점유만 하므로 쓰지 않고 대기한다.

타이밍 차트 ② — 층 정렬 · 분류 중 아님 (층 다름 → 이동 → 허가)

  1. ① 층 다름 — WCS가 CurFloor(=2)·Ready 읽음. AGV층(1)과 달라 TgtFloor==0이므로 1 기입 → WRONG_FLOOR
  2. ② 이동 중 — 3D가 1층으로 이동. 이동 중엔 Ready=0이라 받을 수 없음 → BUSY. TgtFloor≠0이라 덮어쓰지 않음(핑퐁 차단). RCS 500ms 재호출
  3. ③ 도착 — PLC가 CurFloor=1 기입 (TgtFloor는 유지). TgtFloor는 도착이 아니라 분류 시작 시 0으로 클리어 — 도착 즉시 비우면 곧바로 다시 써져 왕복하기 때문
  4. ④ 허가 — CurFloor==AGV층 & Ready=1 → allowed=true, 투입 진행

타이밍 차트 ③ — 층 정렬 · 분류 중 (TgtFloor 선기입 → 분류 끝 → 복귀 → 허가)

  1. ① 분류 중·층 다름 — WCS가 Ready=0(분류 중)·CurFloor(=2) 읽음. AGV층(1)과 다르고 분류 중이라 TgtFloor==0이므로 1을 미리 기입 → BUSY
  2. ② 분류 진행 — 3D가 분류를 계속. TgtFloor=1 유지(≠0이라 덮어쓰지 않음). RCS 500ms 재호출(BUSY)
  3. ③ 분류 끝 → 이동 — 분류가 끝나도 TgtFloor=1을 따라 1층으로 복귀(이동)하는 동안엔 Ready=0(이동 중엔 받을 수 없음) → BUSY
  4. ④ 도착·허가 — 도착하면 PLC가 CurFloor=1 기입(TgtFloor 유지)하고 Ready 0→1(이제 정지·수용 가능). 층 일치 → allowed=true
  5. ⑤ 투입 → 분류 시작 — AGV 투입(IF-10) 후 3DS가 새 분류를 시작(Ready 1→0). 이때 PLC가 TgtFloor=0 클리어 — 도착 즉시가 아니라 분류 시작 시 비워 그 사이 성급한 재기입(왕복)을 막는다

6 확정 사항 (결정됨)

  • PLC가 주는 상태 = 수용 가능 여부(Ready=D4.2) — Ready=0은 분류 중 또는 이동 중(둘 다 받을 수 없음). FULL(만재)·PAUSED(일시정지)·OFFLINE은 WCS가 판단한다(만재=예약/수량, 일시정지=운영 상태, OFFLINE=폴 타임아웃). BUSY/FULL 구분용 별도 PLC 비트는 두지 않는다.
  • TgtFloor 쓰기 = 0일 때 + (층 다름 또는 분류 중) — TgtFloor==0이고 층이 다르거나 분류 중(BUSY)이면 AGV 층을 써서 그 층으로 이동(층 다름)하거나 분류 후 복귀(분류 중)시킨다. 진행 중(≠0)엔 덮어쓰지 않아 핑퐁 차단. 도착 시엔 CurFloor만 기입(TgtFloor 유지), 분류 시작(BUSY 진입) 시 TgtFloor=0 클리어 — 도착 즉시 비우면 왕복 우려. FULL/PAUSED/OFFLINE은 쓰지 않고 대기.
