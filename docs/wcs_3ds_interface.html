3 핸드셰이크 프로토콜

공통 규칙 — ① 쓰기 전 해당 Flag=0 확인(아직 안 읽힌 값 덮어쓰기 방지). ② 쓴 쪽이 Flag=1, 읽은 쪽이 Flag=0으로 내림(대칭). ③ C_Flag/R_Flag로 한 건씩 직렬 처리.

C 영역 — 셀 지정 (WCS → PLC)

  1. WCS: C_Flag==0 확인 → C_CellNo·C_Seq 쓰기 → C_Flag=1
  2. PLC: C_Flag=1 감지 → C_CellNo·C_Seq 읽기 → 읽은 직후 C_CellNo·C_Seq·C_Flag = 0 클리어 → 해당 셀로 적재 수행

R 영역 — 적재 완료 (PLC → WCS)

  1. PLC: R_Flag==0 확인 → 적재 결과 R_CellNo·R_Seq 쓰기 → R_Flag=1
  2. WCS: R_Flag 폴링 → 1이면 R_CellNo·R_Seq 읽기 → R_Seq == C_Seq 대사(유실·중복 검출) · 틸트 시각 기록 → 클리어는 즉시가 아니라 Ready==1(복귀 완료) 시점에 R_CellNo·R_Seq·R_Flag = 0 + 복귀 시각 기록(R_Flag==1 때 이미 Ready==1이면 즉시)
요약 — “쓰는 쪽은 Flag=0 확인 후 쓰고 1로 set, 읽는 쪽은 읽고 0으로 clear.” C는 WCS가 쓰고 PLC가 클리어, R은 PLC가 쓰고 WCS가 클리어 — 대칭(단 R 클리어는 Ready==1 게이트, 아래). C_Flag(D4.0)·R_Flag(D4.1)는 같은 워드 D4의 비트이므로, set/clear 시 D4를 읽어 해당 비트만 바꿔 다시 쓴다(read-modify-write · 상대 플래그 비트 보존).
R 클리어 = Ready==1 게이트 · 처리시각 3종(2026-07-21). R_Flag==1에서 WCS는 읽고 대사·틸트 시각(tiltedAt)만 기록하고, 복귀 완료(Ready 0→1) 시점에 R을 클리어하며 복귀 시각(returnedAt)을 기록한다 — 분류 시작~복귀 완료 전체 소요를 계측하기 위함. 세 시각 depositedAt(3DS 투입=IF-10)·tiltedAt(셀 틸트=R_Flag==1)·returnedAt(복귀 완료=Ready 0→1)은 sorter_command 신규 컬럼(마이그레이션=코드 스프린트).

타이밍 차트 ① — 셀 지정 → 적재 완료 (C/R 핸드셰이크)

  1. ① WCS 쓰기 — C_Flag==0 확인 → C_CellNo·C_Seq 쓰기 → C_Flag=1
  2. ② PLC 읽고 클리어 — PLC가 C_Flag=1 보고 C 값 읽음 → C_CellNo·C_Seq·C_Flag=0 클리어
  3. ③ N초 → 적재 — PLC가 N초 대기(틸트 낙하 안착) 후 지정 셀에 적재
  4. ④ PLC 통지 — R_Flag==0 확인 → R_CellNo·R_Seq 쓰기 → R_Flag=1
  5. ⑤ WCS 읽음 (클리어=복귀 후) — WCS가 R_Flag 폴링 → R 값 읽고 R_Seq==C_Seq 대사 · 틸트 시각 기록. 클리어(R_CellNo·R_Seq·R_Flag=0)는 Ready==1(복귀 완료) 시점에 하며 복귀 시각을 기록(위 note)

4 층 제어 (폐루프)

인덕션 기반 2층(1·2층) 제어 — 목표 층 F는 인덕션 번호에서 파생한다(설정 InductionFloorMap: inductionNo→floor). TgtFloor에는 상수 2가 아니라 인덕션 파생 층 F(1/2)를 쓴다. 소터 한 대가 정렬로 두 층을 겸하며, CurFloor는 현재 정렬된 층이고 그 층에서만 수용 가능하다. 2026-06-22 "운영 2층 고정(항상 2)" 결정은 폐지(2026-07-21).

층은 인덕션 스캔 시점(IF-05 목적지 조회)에 확정되므로, WCS는 IF-05 시점에 3DS를 층 F로 정렬한다(TgtFloor=F, 게이트 통과 시 — 도착 전 선정렬). 과거 IF-09 도착 트리거는 폐지. 소터가 F층 정렬·정지·수용 가능하면 IF-08 상태 알림을 F층 호스트로 푸시한다(1층 192.168.0.151:3000·2층 192.168.0.152:3000). 층은 페이로드에 없고 수신 호스트로 라우팅된다.

  1. WCS: 폴링으로 CurFloor(D5)·Ready(D4.2)를 읽어 층 F 수용 가능 여부(ready)를 산출 — 기준은 CurFloor=F & Ready=1 (Ready=0 = 분류 중 또는 이동 중)
  2. 분류 중 아님(Ready=1) + F층 정렬(CurFloor=F) → ready=true → RCS가 투입
  3. 분류 중 아님(Ready=1) + F층 아님 → ready=false → WCS가 TgtFloor=F 쓰기(아래)
  4. 분류 중 또는 이동 중(Ready=0) → ready=false. 분류 중이면 곧 끝나므로 아래 조건으로 TgtFloor=F를 미리 써 둔다(이동 중이면 이미 설정됨)
  5. TgtFloor 쓰기 조건 — TgtFloor==0 이고 (CurFloor≠F 또는 분류 중)이면 WCS가 TgtFloor(D6)=F를 쓴다 → F층 아니면 이동, 분류 중이면 분류를 마친 뒤 F층 복귀
  6. PLC: TgtFloor(=F) 층으로 이동(또는 분류 후 복귀) → 도착하면 CurFloor(D5)=F 기입 (TgtFloor는 유지)
  7. PLC: 분류를 시작할 때(Ready=0 진입) TgtFloor=0 클리어 — 도착 즉시 비우면 곧바로 다시 써져 왕복할 수 있어, 분류 시작까지 F층(TgtFloor=F)을 붙들어 둔다
TgtFloor 쓰기 = 0일 때 + (CurFloor≠F 또는 분류 중) · 인덕션 파생 층 F — 이전 명령이 진행 중(TgtFloor≠0)이면 덮어쓰지 않아 핑퐁(왕복)을 차단하고, F층이 아니거나 분류 중이면 TgtFloor=F를 써서 F층으로 이동/복귀시킨다. 쓰기 트리거는 IF-05 목적지 조회 시점(인덕션에서 F 확정). 도착 시엔 PLC가 CurFloor만 기입하고(TgtFloor 유지), 분류 시작 시(BUSY 진입) TgtFloor=0 클리어. FULL·PAUSED·OFFLINE은 장기 차단이라 쓰지 않고 대기한다.

타이밍 차트 ② — F층 정렬 · 분류 중 아님 (F층 아님 → F층 이동 → ready · F=인덕션 파생)

  1. ① F층 아님 — WCS가 CurFloor(≠F)·Ready 읽음. F층이 아니라 ready=false, TgtFloor==0이므로 F 기입(트리거=IF-05 인덕션 파생 층)
  2. ② 이동 중 — 3D가 F층으로 이동. 이동 중엔 Ready=0이라 받을 수 없음 → ready=false. TgtFloor≠0이라 덮어쓰지 않음(핑퐁 차단). WCS가 상태 감시 지속
  3. ③ 도착 — PLC가 CurFloor=F 기입 (TgtFloor는 유지). TgtFloor는 도착이 아니라 분류 시작 시 0으로 클리어 — 도착 즉시 비우면 곧바로 다시 써져 왕복하기 때문
  4. ④ ready — CurFloor==F & Ready=1 → ready=true → 상태 푸시(IF-08, F층 호스트) → RCS 투입

타이밍 차트 ③ — F층 정렬 · 분류 중 (TgtFloor=F 선기입 → 분류 끝 → F층 복귀 → ready · F=인덕션 파생)

  1. ① 분류 중·F층 아님 — WCS가 Ready=0(분류 중)·CurFloor(≠F) 읽음. ready=false, F층이 아니고 분류 중이라 TgtFloor==0이므로 F를 미리 기입(트리거=IF-05 인덕션 파생 층)
  2. ② 분류 진행 — 3D가 분류를 계속. TgtFloor=F 유지(≠0이라 덮어쓰지 않음). ready=false, WCS 상태 감시 지속
  3. ③ 분류 끝 → 이동 — 분류가 끝나면 TgtFloor=F를 따라 F층으로 복귀(이동)하는 동안엔 Ready=0(이동 중엔 받을 수 없음) → ready=false
  4. ④ 도착·ready — 도착하면 PLC가 CurFloor=F 기입(TgtFloor 유지)하고 Ready 0→1(이제 정지·수용 가능). F층 정렬 → ready=true → 상태 푸시(IF-08, F층 호스트)
  5. ⑤ 투입 → 분류 시작 — AGV 투입(IF-10) 후 3DS가 새 분류를 시작(Ready 1→0). 이때 PLC가 TgtFloor=0 클리어 — 도착 즉시가 아니라 분류 시작 시 비워 그 사이 성급한 재기입(왕복)을 막는다

6 확정 사항 (결정됨)

  • PLC가 주는 상태 = 수용 가능 여부(Ready=D4.2) — Ready=0은 분류 중 또는 이동 중(둘 다 받을 수 없음). FULL(만재)·PAUSED(일시정지)·OFFLINE은 WCS가 판단한다(만재=예약/수량, 일시정지=운영 상태, OFFLINE=폴 타임아웃). BUSY/FULL 구분용 별도 PLC 비트는 두지 않는다.
  • TgtFloor 쓰기 = 0일 때 + (CurFloor≠F 또는 분류 중) · 인덕션 파생 층 F — TgtFloor==0이고 F층이 아니거나 분류 중(BUSY)이면 TgtFloor=F를 써서 F층으로 이동/복귀시킨다(층 F=인덕션 파생; 2026-06-22 "운영 2층 고정" 폐지 — 2026-07-21). 쓰기 트리거는 IF-05 목적지 조회 시점. 진행 중(≠0)엔 덮어쓰지 않아 핑퐁 차단. 도착 시엔 CurFloor만 기입(TgtFloor 유지), 분류 시작(BUSY 진입) 시 TgtFloor=0 클리어. FULL/PAUSED/OFFLINE은 쓰지 않고 대기. IF-08 push는 층별 호스트로 라우팅(층은 페이로드에 없음).
