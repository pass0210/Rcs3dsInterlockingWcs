WCS ↔ RCS ↔ 3D Sorter · Master Spec

WCS ↔ RCS / 3D Sorter 통합 인터페이스 정의서 실시간 연속 운영. 로봇이 트레이 상품을 목적지(슈트 또는 3D 셀)에 한 번에 전량 틸트. ※ PLC 주소는 3DS 제공 맵 기준(§7), 시간값은 예시(현장 조정).

00 개요 & 시스템 구성

WCS(자사, 오더 보유)가 RCS(AGV·로봇)와 3D Sorter(VEICHI PLC)를 연동한다. 로봇이 인덕션에서 트레이를 받아, 목적지(슈트 또는 3D 셀)에 상품 전량을 한 번에 틸트한다.

  • 실시간 연속 운영 — 배치(차수) 시작/종료 개념 없음. 인덕션부터 바로 처리(작업 데이터 수신·시작·종료·결과 전송 IF 제외).
  • 목적지 = chuteNo — 슈트/3D를 하나의 번호로 식별(메시지에 destType 없음). 투입 보고도 슈트/3D 구분 없이 동일.
  • 한 번에 전량 틸트 — 한 트레이에 같은 상품 여러 개(qty)를 싣고, 한 목적지에 전량을 한 번에. 부분 투입 불가.

05 목적지 조회 (IF-05) 사유

WCS가 목적지(chuteNo)와 수량을 판정한다. 막힘이어도 BUSY/FULL/PAUSED는 그 목적지로 그대로 배정(일시적이라 거부 아님) → 도착 후 IF-08에서 실제 가부 확인.

reason결과동작
NORMALOK · chuteNo전량이 한 곳에 들어감 → 그 목적지로 진행
BUSY / FULL / PAUSEDOK · chuteNo일시적 막힘 → 그 목적지로 보냄. 도착 후 IF-08에서 가부 확인·대기
OVERNG 대기전량이 한 곳(슈트/3D 한 셀)에 안 들어감 → 전량 가능할 때까지 AGV 대기
COMPLETED / NO_DEST / OFFLINENG 대기보낼 곳 없음 → AGV 대기(이동 안 함). OFFLINE은 대체 3D/보류
OVER와 보낼 곳 없음(COMPLETED/NO_DEST/OFFLINE)은 동작이 동일(NG·대기)하여 하나로 묶는다. BUSY/FULL/PAUSED만 “그 목적지로 진행”.

06 투입 가부 (IF-08) — 층 비교 포함

요청 pId · chuteNo · agvNo. WCS가 PLC 상태(Ready D4.2)와 CurFloor(D5 == AGV 층)를 함께 확인한다 — 층이 같아도 분류 중·이동 중(Ready=0)이면 BUSY. 상태·층 비교·이동 명령·반복이 모두 IF-08 안에서 일어나며 RCS가 500ms 간격으로 재호출한다.

조건응답동작
받을 수 있음(Ready=1) · 층 일치allowed = true투입 진행
받을 수 있음(Ready=1) · 층 다름false · WRONG_FLOORWCS가 TgtFloor(D6)에 AGV 층 쓰기(TgtFloor==0일 때) → 그 층으로 이동, 정렬될 때까지 500ms 재호출
분류 중·이동 중(Ready=0) = BUSYfalse · BUSY층이 같아도 BUSY. WCS가 TgtFloor=AGV 층 쓰기(TgtFloor==0일 때) → 분류 끝나면 그 층으로 복귀. 500ms 재호출
막힘 (FULL/PAUSED/OFFLINE)false장기 차단 — 해소될 때까지 500ms 재호출 대기 (TgtFloor 안 씀)

07 3DS PLC 레지스터 + 핸드셰이크

영역워드/비트방향설명
셀 지정 (C) · IF-11C_CellNo(D0) · C_Seq(D1) · C_Flag(D4.0)WCS→PLCWCS가 셀 지정 후 C_Flag=1
적재 완료 (R) · IF-12R_CellNo(D2) · R_Seq(D3) · R_Flag(D4.1)PLC→WCSPLC가 적재 후 R_Flag=1
상태 · 층Ready(D4.2) · CurFloor(D5) · TgtFloor(D6)WCS read / writeReady(0=분류 중→BUSY) · 현재 층(1/2) · 목표 층(0=없음)

핸드셰이크 규칙

  1. 쓰기 전 해당 Flag=0 확인 — 아직 안 읽힌 값을 덮어쓰지 않도록(C_Flag / R_Flag 각각).
  2. C 영역: WCS가 C_Flag=0일 때 C값 쓰고 C_Flag=1 → PLC가 C값 읽고 C_CellNo·C_Seq·C_Flag=0 클리어 후 적재.
  3. R 영역: PLC가 R_Flag=0일 때 R값 쓰고 R_Flag=1 → WCS가 R값 읽고 R_Seq==C_Seq 대사 후 R_CellNo·R_Seq·R_Flag=0 클리어.
  4. 층 폐루프: WCS가 TgtFloor==0이고 (층 다름 또는 분류 중)일 때 TgtFloor=AGV 층 쓰기 → 층 다르면 이동, 분류 중이면 분류 후 복귀 → 도착 시 PLC가 CurFloor 기입(TgtFloor 유지) → 다음 IF-08에서 WCS가 CurFloor 읽어 비교. TgtFloor는 분류 시작(BUSY 진입) 시 0으로 클리어(도착 즉시 비우면 곧바로 다시 써져 왕복). TgtFloor≠0이면 덮어쓰지 않아 핑퐁 차단.
“쓰는 쪽은 Flag=0 확인 후 쓰고 1, 읽는 쪽은 읽고 0.” C는 WCS가 쓰고 PLC가 클리어, R은 PLC가 쓰고 WCS가 클리어 — 대칭. 틸트 낙하 대기는 PLC가 N초 지연으로 처리(WCS 측 지연 없음). 모든 레지스터는 Holding Register(읽기 FC03 · 쓰기 FC06/16)이고 C_Flag·R_Flag·Ready는 워드 D4의 비트0·1·2다 — 한 비트만 바꿀 땐 D4 read-modify-write(상대 비트 보존). 주소는 3DS 제공 맵(D0~D4) + 층 신설(D5·D6).

08 핵심 플로우

① 인덕션·목적지 조회→ ② 투입 가부(층 비교)→ ③ 투입(슈트/3D 공통)
  1. ① 인덕션·목적지 조회 — 스캔(qty) → (판독 실패 시 NO_READ·재스캔/리젝트) → IF-05(라인 투입 기록 + 목적지·수량 판정) → OK·chuteNo(BUSY/FULL/PAUSED 포함) / NG·대기(OVER·COMPLETED·NO_DEST·OFFLINE).
  2. ② 투입 가부 — IF-08 반복(500ms): CurFloor 비교 → 허가 / WRONG_FLOOR(TgtFloor 쓰기) / 막힘.
  3. ③ 투입 — IF-10 투입 보고 → IF-11 셀 지정(C_Flag=0 확인 후 1) → PLC가 C 읽고 초기화 → 적재(R_Flag=0 확인 후 1) → WCS R_Flag 폴링 → R 읽고 초기화. 이후 분류 후 복귀(TgtFloor 층으로 이동 → 도착 시 CurFloor 기입).

10 확정 사항 (PLC 협의 완료)

  • PLC가 주는 상태 = 수용 가능 여부(Ready=D4.2) — Ready=0은 분류 중 또는 이동 중(둘 다 받을 수 없음). FULL(만재)·PAUSED(일시정지)·OFFLINE은 WCS가 판단한다(만재=예약/수량, 일시정지=운영 상태, OFFLINE=폴 타임아웃). BUSY/FULL 구분용 별도 PLC 비트는 두지 않는다.
  • TgtFloor 쓰기 = 0일 때 + (층 다름 또는 분류 중) — TgtFloor==0이고 층이 다르거나 분류 중(BUSY)이면 AGV 층을 써서 그 층으로 이동(층 다름)하거나 분류 후 복귀(분류 중)시킨다. 진행 중(≠0)엔 덮어쓰지 않아 핑퐁 차단. 도착 시엔 CurFloor만 기입(TgtFloor 유지), 분류 시작(BUSY 진입) 시 TgtFloor=0 클리어(도착 즉시 비우면 왕복 우려). FULL/PAUSED/OFFLINE은 쓰지 않고 대기.
  • 플래그 위치 확정 — C_Flag=D4.0 · R_Flag=D4.1 · Ready=D4.2 (3DS 맵). 같은 워드(D4)라 한 비트만 바꿀 땐 read-modify-write.
